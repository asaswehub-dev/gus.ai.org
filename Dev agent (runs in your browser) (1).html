Dev agent

An AI that writes code, runs it, finds bugs and fixes them. It runs entirely inside this page, on your own graphics card. No API key, no account, nothing to install.

Starting…

The first start downloads the model once (1 to 5 GB depending on the size you pick) and keeps it for next time. Needs a recent desktop Chrome or Edge, an internet connection for that first download, and a graphics card with enough memory. Smaller models are faster but make more mistakes.

Paste code with a bug, or describe something to build.
