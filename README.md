# Skippy — AI Chat

A playful, browser-based AI chatbot. Skippy runs locally in your browser using WebGPU and WebLLM, so no API key or account is required. The selected model is downloaded on first use and cached by the browser; model downloads can be large and require a compatible browser/device.

Open [the web app](https://asaswehub-dev.github.io/gus.ai.org/) in a recent WebGPU-capable browser, choose a model, and select **Load model**. Your chat stays in the current page and is not sent to an application server. AI responses can be inaccurate, so verify important information.

## Image generation

Open [Skippy Image Studio](https://asaswehub-dev.github.io/gus.ai.org/image-generator.html) to generate images from text prompts. This tool sends prompts to the Pollinations image-generation service, so image generation is not local like chat. A publishable API key can be entered if the service requires one; do not enter a secret key in this browser app.
