# Skippy — AI Chat

A lightweight browser-based AI chat app. Skippy runs in the browser with WebGPU and WebLLM, and it can also generate a local API-style token for your own tools.

## Quick start

Open the site in a recent desktop browser with WebGPU enabled, choose a model, and press Load model.

## API key generator

Open the [API key generator](https://asaswehub-dev.github.io/gus.ai.org/api-key-generator.html) to create a random token in your browser. The token is generated locally and stored in the browser only for this app.

## Image generation

Open [Skippy Image Studio](https://asaswehub-dev.github.io/gus.ai.org/image-generator.html) to generate images from text prompts.
